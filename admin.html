🖼️ Ảnh nền & ảnh cô dâu chú rể

Ảnh sẽ được tự động nén nhỏ lại và nhúng thẳng vào file data.js, bạn không cần upload ảnh riêng.

Ảnh bìa là gì? Là ảnh hiện ra khi bạn dán link vào Zalo / Messenger. Ảnh này phải là một file riêng trong repo tên đúng là anh-bia.jpg — Zalo không đọc được ảnh nhúng trong data.js.
Sau khi chọn ảnh nền ở trên, bấm ⬇ Tải ảnh bìa rồi upload file anh-bia.jpg lên GitHub cùng với data.js.

📨 Nhận xác nhận qua Telegram

Khi khách bấm "Gửi xác nhận", tin nhắn sẽ bay thẳng vào Telegram của bạn.

Làm theo đúng 4 bước này:
  1. Mở Telegram, tìm @BotFather, gõ /newbot, đặt tên bot. BotFather trả về một chuỗi dài — copy dán vào ô Bot Token ở trên.
  2. Bấm nút ① Mở bot của tôi — Telegram sẽ mở ra đúng con bot đó. Bấm Start, rồi gõ đại một chữ bất kỳ và gửi. Bot không trả lời gì là bình thường, nó chỉ là cái hộp nhận tin.
  3. Quay lại đây, bấm ② Lấy Chat ID tự động. Ô Chat ID sẽ tự điền.
  4. Bấm ③ Gửi thử một tin nhắn để kiểm tra. Nhận được tin trên Telegram là xong.

Lưu ý bảo mật: repo GitHub của bạn để Public nên ai xem mã nguồn cũng thấy được token này. Hãy tạo bot riêng chỉ dùng cho thiệp cưới, đừng dùng bot đang dùng việc khác. Rủi ro tối đa là có người nghịch gửi tin spam vào bot đó — khi cưới xong bạn vào BotFather gõ /deletebot là xong.

🚀 Lưu thẳng lên website

Bấm một nút là nội dung lên thẳng thiệp thật, không phải tải file rồi upload tay nữa.

Lấy token thế nào (làm một lần duy nhất):
  1. Mở github.com/settings/personal-access-tokens/new
  2. Token name: gõ đại thiep-cuoi
  3. Expiration: chọn 90 days hoặc xa hơn
  4. Repository access: chọn Only select repositories → chọn thiep-cuoi
  5. Permissions → Repository permissions → tìm dòng Contents → đổi thành Read and write
  6. Bấm Generate token, copy chuỗi hiện ra và dán vào ô trên

Token này chỉ nằm trong trình duyệt máy bạn, không được ghi vào website. Nó chỉ có quyền sửa đúng repo thiệp cưới, không đụng được repo khác.

📤 Cách thủ công (nếu không muốn dùng token)

  1. Bấm Tạo file data.js ở thanh dưới cùng.
  2. File data.js được tải về máy bạn.
  3. Nếu có đổi ảnh nền, bấm thêm ⬇ Tải ảnh bìa để lấy anh-bia.jpg.
  4. Vào github.com/Tuankull98/thiep-cuoi → bấm Add file → Upload files.
  5. Kéo các file vừa tải vào → bấm Commit changes.
  6. Đợi 1–2 phút, mở lại link thiệp là thấy nội dung mới.
