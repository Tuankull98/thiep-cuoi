📨 Nhận xác nhận qua Telegram

Khi khách bấm "Gửi xác nhận", tin nhắn sẽ bay thẳng vào Telegram của bạn.

Cách lấy Token và Chat ID:
  1. Mở Telegram, tìm @BotFather, gõ /newbot, đặt tên bot. BotFather trả về một chuỗi dài — đó là Bot Token.
  2. Tìm tiếp @userinfobot, bấm Start. Nó trả về số Id của bạn — đó là Chat ID.
  3. Quan trọng: quay lại tìm bot vừa tạo, bấm Start một lần. Không làm bước này Telegram sẽ chặn, bot không nhắn cho bạn được.

Lưu ý bảo mật: repo GitHub của bạn để Public nên ai xem mã nguồn cũng thấy được token này. Hãy tạo bot riêng chỉ dùng cho thiệp cưới, đừng dùng bot đang dùng việc khác. Rủi ro tối đa là có người nghịch gửi tin spam vào bot đó — khi cưới xong bạn vào BotFather gõ /deletebot là xong.

📤 Tạo file và đưa lên GitHub

  1. Bấm Tạo file data.js ở thanh dưới cùng.
  2. File data.js được tải về máy bạn.
  3. Vào github.com/Tuankull98/thiep-cuoi → bấm Add file → Upload files.
  4. Kéo file data.js vừa tải vào → bấm Commit changes.
  5. Đợi 1–2 phút, mở lại link thiệp là thấy nội dung mới.
